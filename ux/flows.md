# UX Flows
This file will describe the main user flows for PayNest.
Example flows:
- Sign up and onboarding
- Add allowance or income
- Track daily expenses
- Save money weekly
- View reports


# Core User Flows

## Flow 1: Onboarding → Dashboard
- Open app
- Sign up (name, email, password)
- Add allowance or income source
- Quick tutorial
- Land on dashboard

## Flow 2: Dashboard → View Spending
- From dashboard, tap "Expenses"
- See list of recent spending
- Filter by category (food, transport, social)
- Return to dashboard

## Flow 3: Dashboard → Create Savings Goal
- From dashboard, tap "Savings"
- Enter goal name and target amount
- Choose frequency (weekly, monthly)
- Confirm goal
- Goal appears on dashboard
